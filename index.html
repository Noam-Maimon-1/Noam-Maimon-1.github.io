LectureFlow

Python · Whisper · Claude API · ffmpeg · Docker · pytest

DownloadConvertTranscribeAnalyzeRender
View on GitHub

A modular pipeline that turns recorded university lectures into structured study guides.

  • Five independent stages: fetch the recording, extract audio, transcribe with Whisper, analyze with the Claude API, render an offline HTML guide.
  • The analyzer outputs a structured JSON schema: topics, key terms, common misconceptions and review questions.
  • Config through .env with per-run CLI overrides; covered by a pytest suite.

In progress: improving Hebrew transcription quality.
